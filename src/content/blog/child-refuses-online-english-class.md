## 先說結論：不要只問「要不要堅持上完」

孩子上線上英文不開口、上課前哭，或幾分鐘就離開座位時，家長最容易卡在兩個極端：

- 現在讓她停，以後是不是遇到困難都會放棄？
- 已經哭成這樣，繼續上是不是在逼孩子？

真正需要判斷的，不是「哭了就停」或「約好的課一定上完」，而是孩子當下是否仍保有可用的參與方式，以及在降低要求後，情緒能不能逐漸恢復。

有些孩子雖然不說話，仍看著老師、聽教材、願意指認或點頭；有些孩子則持續哭泣、逃離、遮住螢幕，已經無法接收互動。兩種情況都可能被大人描述成「不配合」，實際需要的處理卻不一樣。

## 我們家的真實經驗：從第一次沉默，到第11堂課前哭泣

女兒4歲第一次試聽TutorJr一對一外師課時，平常很活潑的她，從老師進入教室後就整個僵住。她幾乎不敢開口，只能用很小的聲音跟著念。

前10堂課，她不是突然變得不怕，而是逐漸累積一些可以回應的方式：從很小聲跟讀，到願意回答老師、跟著做活動。這段變化讓我們以為，她已經慢慢適應線上外師課。

這也回答了很多家長會搜的幾個問題：孩子不敢跟外師說話，是不是老師不適合？上課哭要不要繼續？家長陪課會不會讓孩子更依賴？我們的經驗是，這些問題不能只看某一堂有沒有完成，而要看降低要求後，孩子是否仍願意用眼神、動作、圈選或畫畫留在互動裡。

但第11堂課前，她一直哭，說學英文太難了。我們先解釋已經約好時間、也試著勸她去上課，都沒有用。老師進入教室後，我先向老師說明她正在哭，原本甚至打算關掉iPad。

最後，我再問女兒：如果現在害怕說話，可以先不說；媽媽可以抱著妳上課，等想說時再說。

她答應了。課程前10分鐘，她完全沒有開口，但仍願意看著畫面，也會依老師的引導圈選、畫畫。情緒慢慢穩定後，她才逐漸開始出聲。

這一次，我們選擇陪著完成，是因為她在降低口說要求後，仍願意用圈選和畫畫參與，而且情緒逐漸恢復。這不代表當時的選擇一定適用於下一次，更不代表所有哭泣的孩子都應被要求繼續上課。

## 孩子不開口，不等於沒有參與

孩子不敢跟外師說話時，家長常把「有沒有說英文」當成唯一標準。但對剛接觸陌生老師、陌生口音或視訊互動的幼兒來說，口說可能是壓力最高的回應方式。

可以先觀察孩子是否願意：

- 看老師或教材；
- 用眼神追著活動移動；
- 指圖片、圈選或點選答案；
- 點頭、搖頭或比動作；
- 拿出老師指定的物品；
- 畫畫或模仿動作；
- 用單一聲音或很小聲的單字回應。

這些反應不能直接證明孩子聽懂所有內容，也不等於已經適應課程；但它們表示孩子可能仍留在互動裡。老師若能先接受非口語參與，再逐步邀請孩子發出聲音，通常比連續要求「Say it」更容易看出孩子真正能承受的難度。

相反地，孩子完全沒有口語回應，也不能立刻解讀成故意不配合、沒有學習動機或不適合英文。她可能正在觀察、需要更長等待時間、聽不懂問題，也可能被陌生成人持續注視而僵住。

## 幼兒上英文課哭：先看兩組判斷燈號

哭泣本身不能直接決定要繼續或停止。家長可以先降低要求，再觀察孩子接下來的變化。

### 綠燈：可以先陪伴觀察

- 孩子雖然沉默，但仍看著老師或教材；
- 願意圈選、點頭、畫畫或用動作回應；
- 能接受家長抱著、坐在旁邊或牽手；
- 老師降低問題難度後，孩子願意做簡單選擇；
- 在不要求立刻說話後，哭聲、呼吸或身體緊繃逐漸緩和；
- 下課後可以平靜談起剛才的活動。

這裡的「觀察」不是要求孩子一定完成整堂。若課程還有15分鐘，可以先觀察2～3分鐘；情緒有恢復，才繼續下一小段。若再次惡化，仍可縮短或結束。

### 紅燈：應先降低難度、縮短或暫停

- 持續哭泣，陪伴後仍無法恢復；
- 明顯害怕老師、鏡頭、聲音或設備；
- 一看到上課通知就躲藏、逃跑或激烈抗拒；
- 課前多次出現強烈身體不適，例如反覆說肚子痛、頭痛或想吐；
- 每堂課後都長時間排斥英文或害怕下一次上課；
- 家長與老師已調整難度、時間或回應方式，情況仍持續惡化；
- 孩子已無法看畫面、聽指令或接受任何形式的互動。

遇到紅燈，不必在當下逼孩子說清楚原因。可以先結束刺激，等情緒穩定後再回顧：是太難、太累、怕陌生老師、討厭被糾正，還是剛好遇到其他生活壓力。

若強烈身體不適反覆出現、影響日常生活，或不只發生在英文課，本文的家庭觀察已不足以判斷原因，應向兒科醫師、兒童心理或教育專業人員諮詢。

## 線上英文坐不住，先分辨是哪一種「離開」

幼兒能不能端正坐滿25分鐘，不是判斷課程是否有效的唯一標準。孩子離開座位，可能代表：

| 課堂表現 | 可能需要觀察 | 可以先怎麼調整 |
|---|---|---|
| 身體一直扭動，但仍看著老師 | 需要動作或姿勢變換 | 允許站著回答、拿實物或比動作 |
| 聽完指令後去拿東西 | 正在用行動參與 | 請老師把找物品變成任務 |
| 每逢題目變難就離開 | 可能聽不懂或怕答錯 | 改成二選一、指認或先示範 |
| 一開始就到處跑 | 時段、疲累或環境可能不合適 | 換精神較好的時段、清空桌面 |
| 持續逃離並拒絕回來 | 壓力可能已超過可承受範圍 | 停止追著教，縮短或結束課程 |

如果孩子需要站著、抱玩偶或在畫面前做動作，但仍能回到老師的互動，這和完全逃離課堂不同。家長要觀察的是注意力能否回來，不是椅子有沒有一直坐好。

也不要一次把所有刺激都拿走。對有些孩子來說，熟悉的玩偶能提供安全感；對另一些孩子，桌上的玩具會讓她無法回到畫面。每次只改一個條件，才知道真正有幫助的是什麼。

## 家長要不要陪線上英文？前期可以，但角色要清楚

家長陪課不一定會造成依賴，也不一定越久越好。對第一次接觸幼兒一對一外師的孩子，家長可以先成為「安全基地」，讓孩子知道卡住時有人在旁邊。

### 陪課時可以做

- 課前告訴老師孩子今天的情緒與可接受的回應方式；
- 幫孩子把「我不敢說」轉成「可以先指給老師看」；
- 抱著、牽手或坐在鏡頭外，協助情緒穩定；
- 示範一次動作，但把等待時間留給孩子；
- 發現壓力升高時，向老師提出降低難度或提前結束；
- 課後記下哪個活動讓孩子恢復參與。

### 陪課時避免做

- 每一題都翻譯；
- 老師一問就立刻代答；
- 扶著孩子的手選答案；
- 在旁邊不斷提醒「快說、老師在等」；
- 用獎勵或責備要求一定坐完整堂；
- 把家長離開教室當成孩子進步的唯一指標。

我們第11堂採用「媽媽抱著上課」，是一次情境調整，不是固定上課模式。若接下來幾堂情緒穩定，可以從抱著改為坐旁邊、退到鏡頭外，再短暫離開；若一退開孩子就失去所有參與，也不必硬照時間表退出。

## 當下可以怎麼做？5步驟處理順序

### 1. 先停止說服，描述孩子的狀態

比起反覆說「英文不難」「老師人很好」，可以先說：

> 「妳現在很不想上，也覺得要說英文很難。我先陪妳。」

描述不等於答應取消，也不是認定孩子永遠做不到；它只是先讓孩子不用一邊承受情緒，一邊反駁大人的勸說。

### 2. 找出最低可接受的參與方式

不要先問「妳要不要上課？」再和孩子僵持，可以提供具體選擇：

- 先看老師，不用說；
- 用手指出答案；
- 只做動作；
- 先畫一題；
- 媽媽坐旁邊兩分鐘；
- 先跟老師打招呼，再決定是否繼續。

如果連最低門檻都無法接受，就先停下來。

### 3. 請老師同步降低難度

家長可以直接告訴老師：

> She is feeling nervous today. Could she point, circle or draw first? Please give her more time.  
> 她今天有點緊張，可以先用指認、圈選或畫畫回答嗎？也請多給她一點時間。

真正適合幼兒的老師，不只會逗孩子笑，也應能接受沉默、延長等待、減少連續提問，並用非口語活動重新建立互動。

### 4. 設一個短觀察點，不預設一定上完

例如先陪2～3分鐘，再看：

- 情緒有沒有緩和；
- 是否重新看向畫面；
- 願不願意做一個動作或選擇；
- 老師調整後是否有幫助。

如果有改善，可以再進行一小段；如果沒有，不必因為已經開始就硬撐到下課。

### 5. 課後只回顧一件可確認的事

可以說：「妳剛才很緊張，後來有用畫畫告訴老師答案。」  
不要說：「妳看，撐下去就沒事了。」也不要急著追問下次還要不要上。

前一句描述孩子實際完成的行動；後一句容易把複雜的情緒，簡化成大人堅持就是對的。

## 小孩排斥英文怎麼辦？用幾堂課的變化判斷，不只看一天

單單一堂哭泣可能和疲累、生病、作息、老師更換或課程突然變難有關；但若每堂都出現，便不能只用「適應期」解釋。

可以連續記錄3～5堂：

| 觀察項目 | 本堂紀錄 |
|---|---|
| 課前精神與身體狀態 |  |
| 看到老師前的情緒 |  |
| 第一個可用的參與方式 |  |
| 哪個活動開始卡住 |  |
| 家長或老師做了什麼調整 |  |
| 調整後是恢復、維持或惡化 |  |
| 下課後多久恢復平靜 |  |
| 是否願意再談英文活動 |  |

若反應逐堂緩和，孩子可用的參與方式增加，可能只是需要較慢的適應；若害怕的時間變長、身體不適增加，或連原本喜歡的英文活動也一起排斥，就應先暫停並重新檢查老師、難度、課長、頻率與課型。

## 常見問題

### 孩子完全不開口，這堂課還有意義嗎？

要看她是否仍在接收與回應。看老師、依指令圈選或做動作，表示可能仍有互動；但不能因為孩子坐在畫面前，就推論她有理解或學到。若長期只能沉默參與，仍要調整老師、難度或課型。

### 哭一次就應該停課嗎？

不一定。先看降低要求後是否恢復，以及哭泣是否反覆發生。一次情緒波動和每堂持續恐懼，需要不同處理。

### 家長陪課會不會讓孩子永遠依賴？

陪伴本身不等於依賴。關鍵是家長有沒有替孩子回答，以及情緒穩定後能否逐步降低協助。若陪了很多堂仍無法減少，應檢查課程是否太難、老師互動是否合適，而不是只責怪孩子依賴。

### 孩子坐不住，是不是還不適合線上英文？

不一定。先看她能否透過站立、動作或找物品回到互動。若不論如何調整都持續逃離、情緒惡化或無法接收老師，才需要考慮縮短、暫停或改用其他學習方式。

### 換老師會不會讓孩子更難適應？

固定老師可能增加熟悉感，但若孩子持續害怕某位老師的說話速度、提問方式或糾正方式，換老師也可能是必要調整。一次只改一個主要條件，再觀察2～3堂，比同時換老師、教材與時段更容易判斷。

## 最後：那一堂課的完成，不是「堅持一定正確」的證明

第11堂課，我們最後選擇由媽媽抱著陪上。前10分鐘女兒沒有開口，卻仍願意圈選、畫畫，後來才逐漸出聲。

我現在更願意這樣記錄那次經驗：

> **我們這一次選擇陪著完成，是根據女兒當下仍願意以圈選和畫畫參與；這不代表所有哭泣的孩子都應被要求繼續上課。**

家長不需要在每一次哭泣中證明自己夠堅持，也不需要因為暫停一堂課就認定孩子不適合英文。更重要的是看懂：孩子現在還能用什麼方式參與？調整後有沒有恢復？同樣的痛苦是否反覆出現？
