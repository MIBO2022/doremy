## 先說結論：不要一次考六項，也不要只看答對幾題

孩子在英文 App 裡會念單字、完成配對，或跟著熟悉讀本念出整句，家長很自然會想知道：她是真的會拼讀，還是記住了聲音、圖片和操作方式？

判斷的重點不是把孩子叫來「考英文」，而是一次拿掉一種提示，看看孩子在什麼條件下仍能運用已學過的字音規則。

> **一次只選一項，使用2～4個簡單例子，控制在幾分鐘內。孩子疲累、抗拒或開始猜答案就停止，改天再觀察。**

這六個方法不是標準化評量，也沒有「通過四項就算會閱讀」的分數線。它們只幫家長回答三件事：

1. 孩子目前靠什麼線索作答？
2. 已學過的拼讀方法能不能移到新單字？
3. 表現能否隔日保留，並在新句子或讀本中使用？

## 測試前先準備：字不能隨便挑

最常見的 CVC 單字，是由子音、短母音、子音組成，例如 **map、sat、lip**。但「單字很短」不等於「孩子應該會讀」。

準備家庭 CVC 拼讀測試前，先確認：

- 單字只包含孩子已接觸過的字母音；
- 中間母音是孩子學過的短母音；
- 避開尚未教過的字母組合與不規則拼法；
- 新單字符合已學規則，但不是孩子剛剛反覆練過的原題；
- 一次只放2～4個單字，不追求題數。

例如孩子已練過 **cat、hat、rat**，而且也認得 m、s、p 的字母音，才適合另一次嘗試 **mat、sat、pat**。若孩子連其中一個字母音都還不熟，整個單字答不出來，不能直接判定她「不會合音」。

## 測試1：關掉App聲音

### 操作方法

選一個孩子熟悉的 App 單字或短句，先把裝置靜音，或不要按下點讀按鈕。讓文字單獨停留3～5秒，只說：「你想試著看看嗎？」不要先念第一個音，也不要用嘴型暗示。

### 觀察什麼

- 孩子是立刻看文字，還是一直等播放聲音？
- 會不會由左到右看字母？
- 能否說出部分字音，再嘗試合起來？
- 念錯後會自行重試，還是直接隨意猜？

### 答錯可能代表什麼

孩子可能仍以聽音跟讀為主，也可能知道部分字母音，但尚未能獨立合音；若平常都是開著聲音使用 App，突然靜音也可能只是讓她不熟悉。

### 不能過度推論什麼

不能因為關掉聲音後不會念，就說孩子以前「全部是假進步」；原本的跟讀、聲音辨識與參與仍是真實經驗。反過來，一個熟悉單字在靜音後念對，也不能單獨證明她能拼讀新字。

## 測試2：拿掉圖片提示

### 操作方法

把孩子在 App 或繪本中看過的單字，重新打在白紙、空白投影片或無圖字卡上。例如原畫面有老鼠與 **rat**，這次只呈現 **rat**，字體保持清楚簡單。

### 觀察什麼

- 有圖時會答、無圖時是否仍能嘗試？
- 孩子直接說出整個熟字，還是逐音處理？
- 卡住時是否回頭尋找圖片或問「這是什麼」？

### 答錯可能代表什麼

孩子先前可能主要利用圖片理解或猜答案；也可能只是對新字體、紙卡形式不熟悉。答錯本身無法分辨是字母音不熟、合音困難，還是當天不想回答。

### 不能過度推論什麼

無圖仍念對熟字，可能是認得整體字形，也可能是拼讀，兩者不能只靠這一步區分。圖片能協助理解故事，並不是「不好的提示」；只有當目標是檢查文字解碼時，才暫時拿掉。

## 測試3：換成相同規則的新單字

### 操作方法

在確認孩子知道所需字母音後，準備2～3個沒練過、但使用相同拼讀規則的單字。例如熟悉 **cat、hat、rat** 後，另一次呈現 **mat、sat、pat**。不要放圖片，也不要先念答案。

### 觀察什麼

- 是否從左到右處理每個字母或字母組合？
- 能不能說出個別音，再進行 blending 合音？
- 是否把新字直接猜成熟悉的 **cat** 或 **rat**？
- 少量提示後，能否完成剩下的步驟？

### 答錯可能代表什麼

孩子可能記得熟字，卻還不能把規則遷移到新字；也可能卡在某一個字母音、短母音或合音動作。記錄卡在哪一步，比只寫「答錯」更有用。

### 不能過度推論什麼

一次念對新單字，只能說「這次表現支持她可能正在使用拼讀」。不能立刻推論自然發音已經學會、能讀所有 CVC 單字，或已有完整的幼兒英文閱讀能力。

## 測試4：改變單字排列順序

### 操作方法

把孩子練過的2～4張單字卡重新洗牌，或將 App 選項的左右位置改變。只調整順序，不要同時換字體、換新單字又關掉所有提示。

### 觀察什麼

- 孩子是否仍看文字，而不是直接指固定位置？
- 每次洗牌後，會不會重新處理單字？
- 熟悉句子順序打亂後，是否仍能辨認單獨的字？

### 答錯可能代表什麼

孩子可能記住選項位置、故事順序或題型，也可能因規則突然改變而分心。若換位置就卡住，可先回到較少選項，再觀察文字辨認。

### 不能過度推論什麼

打亂後答對，最多只能較有把握地排除「只記位置」，仍不能確認孩子是整字記憶還是拼讀。打亂後答錯，也不代表原先完全沒有學習。

## 測試5：隔一天重新測試

### 操作方法

同一天學過的內容不要立刻重複考。隔至少一天，在自然的共讀或遊戲時間，用不同媒介重新呈現：昨天用 App，今天可用白紙或字卡。只選少量原字與一個規則內新字。

### 觀察什麼

- 沒有剛才的短期記憶，是否仍記得字音或步驟？
- 換成紙卡後，能否使用相同拼讀方法？
- 第二次是更穩定，還是仍需要同樣提示？

### 答錯可能代表什麼

孩子可能尚未保留該字音或規則，也可能只是換媒介後需要重新適應。幼兒的睡眠、情緒和注意力都會影響單次表現，因此先記錄，不急著補考。

### 不能過度推論什麼

隔日一次答對不等於已經穩定；一次答錯也不能判定退步。需要在不同日期、少量例子與不同情境中，看是否逐漸減少提示。

## 測試6：放進新句子或新讀本

### 操作方法

最後才把已練過的字音規則放進一個新短句或可解碼讀本。讀本中的主要單字應配合孩子已學的字母音與拼讀規則，不要拿一般繪本當拼讀考題。讓孩子試讀後，再用選圖、動作或一個簡單問題確認大意。

### 觀察什麼

- 孩子在連續文字中能否找到並讀出規則內單字？
- 遇到新字時，是看字處理，還是依圖片與句意猜？
- 念出句子後，是否大致知道內容在說什麼？
- 是否因文字量增加而明顯疲累，需要成人輪讀？

### 答錯可能代表什麼

單字單獨會讀，放入句子卻卡住，可能表示處理連續文字仍很費力；念得出但不理解，則可能需要補充口語詞彙與內容理解。若書中混入未學規則，也可能是材料不合適，不是孩子原有能力消失。

### 不能過度推論什麼

讀完一本很短的可解碼讀本，不等於已能閱讀所有英文童書；能靠上下文猜到一個字，也不能取代實際解碼。自然發音主要支持單字辨認，閱讀還包括流暢度、詞彙與理解。

## 六項要怎麼分開做？一週只安排2～3次就夠

不要在同一天照著清單從第一項做到第六項。較輕鬆的做法是把觀察藏在原本活動裡：

| 時機 | 只做一件事 | 建議時間 |
|---|---|---|
| App活動結束前 | 關聲音，看一個熟字 | 約1分鐘 |
| 另一天共讀前 | 用無圖字卡看2個熟字 | 約2分鐘 |
| 再隔一天 | 看2個同規則新字 | 約2～3分鐘 |
| 孩子狀態好時 | 洗牌熟字或換媒介 | 約2分鐘 |
| 週末共讀 | 在新短句中找已學規則 | 約3～5分鐘 |

孩子主動想多玩可以繼續；開始閃躲、亂猜、轉移話題或說不要，就結束。**停止不表示家長放棄，而是避免把觀察變成壓力測驗。**

## 家庭觀察紀錄表：記下提示，不只記對錯

以下表格可以直接截圖使用，也可以複製到備忘錄。每次只填一列，不需要每天寫。

| 日期 | 字／短句 | 本次只改變什麼 | 孩子實際怎麼做 | 需要的提示 | 目前可確認 | 目前不能確認 | 下次只驗證一件事 |
|---|---|---|---|---|---|---|---|
| 例：7/25 | mat | 換成同規則新字 | 依序說出 /m/、/a/、/t/，合音時停住 | 家長拉長前兩音 | 知道3個字母音 | 尚不能獨立合音 | 隔日用 sat 重試 |
|  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |

記錄時可以固定使用四句：

- **已觀察到：** 孩子實際看了什麼、說了什麼、怎麼做。
- **可能表示：** 一個保守的解釋。
- **目前不能確認：** 還缺哪個條件或哪一次觀察。
- **下一步驗證：** 下次只改變哪一件事。

例如：

> 已觀察到孩子在無圖字卡上讀出熟悉的 **rat**；可能表示她已認得這個字，但目前不能確認是整字記憶或拼讀。下一步會換成已知字母音組成的新字 **mat**，觀察她是否由左到右合音。

## 怎麼看紀錄結果，而不替孩子貼標籤？

| 多次觀察到的表現 | 較保守的解讀 | 下一步 |
|---|---|---|
| 關聲音後只等待播放 | 目前較依賴聽音跟讀 | 保留跟讀，另練少量字母音 |
| 無圖後熟字仍會念 | 可能認得熟字 | 換同規則新字區分認字與拼讀 |
| 新CVC字能逐音但合不起來 | 已有部分字音知識，合音仍需協助 | 使用連續合音示範，不增加題數 |
| 洗牌後仍辨認相同文字 | 較能排除只記位置 | 隔日換媒介重測 |
| 新句子能讀字但不懂意思 | 解碼與理解發展不同步 | 補充口語詞彙、圖片與對話 |
| 不同日期、媒介都能處理新字 | 較支持已出現拼讀遷移 | 放入符合程度的可解碼短句 |

「自然發音有效嗎」不能用一天的小測試回答。自然發音是協助孩子理解文字與聲音關係的方法；是否正在產生效果，要看孩子能否把學過的對應關係用於規則內新字，而不是只看熟悉 App 的過關數。

## 回到我們家的Day 39：目前適合記成什麼？

Day 39的家庭紀錄顯示，女兒在 App 中接觸 **ar** 字母組合、單字分類與字母選擇活動。從畫面可以確認她願意參與，也正在接觸兩個字母共同代表聲音的概念。

到接近 Day 60，我們觀察到她比較願意主動重播與嘗試短句；因此更適合繼續做「一次拿掉一種提示」的輕量觀察，而不是因為使用時間變長就直接宣布會拼讀。

但僅靠影片，仍無法排除聲音、圖片、固定位置與熟悉題型。因此目前較準確的紀錄是：

> 已觀察到她能在 App 提示下參與 **ar** 活動；可能已熟悉部分聲音與操作，但目前不能確認她能獨立讀出含 **ar** 的陌生單字。下一步應在確認其他字音都學過後，另一天用無聲音、無圖片的新字進行少量觀察。

這樣寫不是看低孩子，而是把「看見了什麼」和「還想知道什麼」分開。

若想先了解跟讀、背誦、認字、拼讀和閱讀的差別，可閱讀[孩子會跟著App念，代表會讀英文嗎？](/blog/repeating-vs-reading-english/)；若需要重新確認字母音、CVC合音與可解碼讀本的學習順序，可閱讀[幼兒自然發音怎麼學？](/blog/preschool-phonics-learning-order/)。

## 最後：家庭小測試的目的，是找到下一步

如何判斷孩子會閱讀，不是把六個項目做完後蓋章「會」或「不會」。家庭觀察真正有用的地方，是發現孩子現在需要哪一種支持：

- 還在等聲音，就先保留跟讀，再增加少量看字機會；
- 容易靠圖片猜，就在另一個輕鬆時段單獨看文字；
- 知道個別字音卻合不起來，就練合音，不急著加新規則；
- 單字會讀、句子卡住，就減少文字量並搭配成人輪讀；
- 念得出卻不理解，就回到口語詞彙與故事對話。

孩子答錯不是測試失敗，而是讓家長看見「提示拿到哪裡時，需要幫忙」。只要一次觀察一件事、允許停止，也不把單次表現放大成能力標籤，這六個小測試就能成為比 App 星星和關卡更實用的家庭紀錄。
